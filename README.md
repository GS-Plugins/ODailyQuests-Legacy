# ODailyQuests Legacy

### Daily Quests, Custom Rewards & Continued Minecraft Compatibility

**ODailyQuests Legacy** is a community-maintained fork of the original [ODailyQuests](https://github.com/Ordwen/ODailyQuests) plugin developed by **Ordwen**, now maintained by **GlowCraft Studios**.

Bring exciting daily challenges to your Minecraft server with randomized quests, customizable rewards, and player progression!

Our goal is to preserve and improve the ODailyQuests experience while providing continued support for legacy Minecraft versions.

---

## ✨ Features

- **Daily Quests** — Give players randomized daily objectives and challenges.
- **Customizable Rewards** — Configure rewards for completing quests.
- **Quest Progress Tracking** — Monitor player progress toward quest completion.
- **Multiple Quest Types** — Challenge players with different activities and objectives.
- **Improved Item Handling** — Fixes for stacked items and quest item interactions.
- **Bug Fixes & Stability** — Improvements to projectile interactions, block-breaking objectives, and other quest mechanics.
- **Legacy Compatibility** — Continued development targeting Minecraft 1.21.11 and earlier supported versions.
- **Configurable Experience** — Customize quests and rewards to suit your server.

## 🚀 Why ODailyQuests Legacy?

Minecraft continues to evolve, but not every server updates to the newest version immediately.

ODailyQuests Legacy exists to provide an actively maintained version of the original plugin for servers that prefer to remain on older Minecraft versions.

Our development priorities include:

- Maintaining compatibility with supported Minecraft versions.
- Fixing bugs and improving stability.
- Improving existing quest mechanics.
- Preserving familiar configuration and gameplay where practical.
- Providing continued maintenance and community support.

## 🛠️ Installation

1. Download the latest compatible ODailyQuests Legacy release from Modrinth.
2. Install any dependencies listed for your selected version.
3. Place the plugin `.jar` file into your server's `plugins` folder.
4. Restart your Minecraft server.
5. Configure the plugin's quests, rewards, and settings.
6. Restart or reload as directed by the plugin documentation when making configuration changes.

**Note:** Always check the compatibility and dependency information for your selected release.

## 🗺️ Development Roadmap

GlowCraft Studios is maintaining two development lines for ODailyQuests.

### ODailyQuests Legacy — 3.x

**Target:** Minecraft 1.21.11 and earlier supported versions

This branch focuses on:

- Bug fixes and stability improvements.
- Maintaining legacy Minecraft compatibility.
- Improving existing quest mechanics.
- Resolving reported issues.
- Continued maintenance of the original plugin experience.

### ODailyQuests 4.0 — Future Development

**Target:** Minecraft 26.1 and newer

Version 4.0 is planned as the next major development generation of ODailyQuests.

The goal is to take advantage of newer Minecraft and Paper APIs while modernizing the plugin's underlying systems.

**ODailyQuests 4.0 is a planned future release and is not included in the Legacy downloads.**
